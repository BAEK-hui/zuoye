# PRD
目标：纯前端个人展示网站，包含个人信息、技能、项目经历及本地管理工作台。
访客可浏览响应式主页，访问项目、发送邮件、下载已上传简历。
管理者可编辑资料、技能列表、项目 JSON，上传或移除头像和 PDF 简历，导入导出 JSON 备份。
验收：保存后刷新保留；上传限制有效；导入异常不覆盖原数据；项目文本安全渲染；移动端可用。
默认内容明确为示例，发布前替换为本人真实资料。
范围限制：管理页是本地编辑器，没有服务端身份认证；localStorage 按浏览器和域名隔离，修改不会同步给其他访客。公开内容更新需修改 app.js 默认数据并重新部署。上传文件仅存浏览器，清理站点数据会丢失，请及时备份。
