# 知行学生信息管理系统

## 启动

需要 Python 3.9 或以上，无第三方依赖。

```powershell
cd D:\Maritime\game\student-system
$env:ADMIN_PASSWORD="请替换为管理员强密码"
$env:STUDENT_PASSWORD="请替换为学生初始强密码"
python server.py
```

浏览器访问 http://127.0.0.1:8000 。首次启动自动创建 SQLite 数据库 students.db 和示例数据。

管理员：`admin` / 由 `ADMIN_PASSWORD` 环境变量指定

示例学生：`20260001` / 由 `STUDENT_PASSWORD` 环境变量指定

另含六位虚构学生（学号 `20260002` 至 `20260007`），初始密码均为 由 `STUDENT_PASSWORD` 环境变量指定，包含不同专业、班级和示例成绩。首次运行自动生成；已有数据库升级时只补充一次，不会覆盖现有档案。邮箱使用 example.com 示例域名。数据库文件不提交到 GitHub。

新增学生自动建立登录账号，账号为创建时学号，初始密码 由 `STUDENT_PASSWORD` 环境变量指定。修改档案学号不会改变登录账号。

管理员可以新增、编辑、删除学生、课程、成绩和公告；学生只能访问自己的档案和成绩，可以修改联系电话和邮箱。所有权限在服务端校验。数据库使用外键、唯一约束和参数化 SQL；密码使用带随机盐的 PBKDF2 哈希。页面支持搜索和移动端布局。

## 项目结构

- server.py：HTTP 服务、身份验证、角色权限、数据库建表及 REST API
- index.html：中文管理员端及学生端
- students.db：运行时生成的持久化数据库，备份时请先停止服务

这是可本地运行的项目版本。会话保存在服务进程内，重启后需重新登录。正式部署前需增加 HTTPS、登录限流、会话过期、密码修改与重置、操作审计及自动备份，并更换演示密码；当前服务仅监听本机。

环境变量仅用于初始化及新增学生，不会重置已有账号密码。请勿将实际密码提交到仓库。
